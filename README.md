# BaixadorDeVideos3000

Aplicativo em Python com interface grafica para baixar videos e audios usando `yt-dlp`.

## Download rapido

Baixe o pacote:

```text
Baixador_YTDLP_Windows_macOS.zip
```

Depois siga o tutorial:

```text
TUTORIAL_DISTRIBUICAO_WINDOWS_MACOS.md
```

Tambem existe uma versao formatada em PDF:

```text
Tutorial_BaixadorDeVideos3000.pdf
```

## Arquivo principal

```text
ytdlp_gui_downloader.py
```

## Atualizacao do app

Use esta URL no campo `URL de atualizacao do app`:

```text
https://raw.githubusercontent.com/NickNery/BaixadorDeVideos3000/main/update_manifest.json
```

## Argumentos extras

Veja exemplos em:

```text
argumentosExtras.txt
```

## macOS

No macOS, rode `Instalar_Dependencias_macOS.command` antes de abrir o app. O arquivo `yt-dlp.exe` e apenas para Windows; se aparecer `Errno 8`, o Mac tentou abrir esse executavel de Windows.
