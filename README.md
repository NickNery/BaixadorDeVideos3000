# BaixadorDeVideos3000

Aplicativo em Python com interface grafica para baixar videos e audios usando `yt-dlp`.

## Download rapido

Baixe o pacote:

```text
Baixador_YTDLP_Windows_macOS.zip
```

Depois siga o tutorial:

```text
TUTORIAL_DISTRIBUICAO_WINDOWS_MACOS.md
```

## Arquivo principal

```text
ytdlp_gui_downloader.py
```

## Atualizacao do app

Use esta URL no campo `URL de atualizacao do app`:

```text
https://raw.githubusercontent.com/NickNery/BaixadorDeVideos3000/main/update_manifest.json
```
