# Versao Python

Esta pasta contem a versao original do BaixadorDeVideos3000 em Python/Tkinter.

## Rodar

```bash
python src/ytdlp_gui_downloader.py
```

No macOS:

```bash
python3 src/ytdlp_gui_downloader.py
```

## Dependencias

```bash
python -m pip install -r requirements.txt
```

## Observacao

As mudancas de regra do programa devem ser mantidas em paralelo com a versao Electron em `../electron`.
Visualmente, esta versao voltou ao design Tkinter anterior, sem os efeitos ReactBits.
